# T05 — Inicializar a estrutura do repositório

## O que foi feito
O repositório ganhou o esqueleto da fatia, sem lógica de negócio: pastas do coletor, dos schemas, do Supabase e do frontend; o pacote Python `collector` com um teste de fumaça; o projeto Vite (React e TypeScript) com Vitest e um teste de renderização; o `supabase/config.toml` gerado por `supabase init`; e os arquivos de exemplo de ambiente, todos com valores vazios.

Os lockfiles Python (`requirements.lock` e `requirements-dev.lock`) foram gerados com hashes por `uv pip compile --generate-hashes` e instalados com `--require-hashes`, como a CI faz. O Supabase CLI entrou como dependência de desenvolvimento na raiz (`package.json`, versão exata).

## Por que foi feito assim
- `pyproject.toml` na raiz com `pythonpath` e `testpaths` do pytest, para `pytest` e `ruff check .` funcionarem na raiz como a CI espera. Ruff ignora `frontend` e `supabase/functions`.
- `uv` no lugar de `pip-compile`: o plano aceita "por exemplo com pip-compile". Os locks foram gerados com `--python-version 3.12`, alvo do projeto, embora o `python3` padrão da máquina seja 3.13.
- `.python-version` com `3.12` e `.nvmrc` com `22` (README 13.1).
- O template do Vite atual usa oxlint como linter e TypeScript 7; mantive. Acrescentei os scripts `typecheck` e `test` que a CI roda. O demo do template (logos, CSS) foi removido; a tela real é da T21a.
- `supabase/.env.functions.example` traz `GROQ_MODEL=` vazio (o README dá um valor padrão, mas a regra é valores vazios) e sem variáveis do Gemini (D6).
- Pastas vazias levam `.gitkeep` para existirem no git. Sem `deno.json`, `scripts/export_schemas.py` ou `.sql`, os jobs de funções, schemas e banco da CI continuam desativados.

## O que foi descartado
Não criei `reports`, `pdf`, `gemini.ts` nem `treasury_official.py` (fora da fatia). Não criei `config/tolerances.yaml`, `retention.yaml` nem os subpacotes `sources/`, `validation/` etc.: pertencem às tarefas seguintes.

## Arquivos principais
- `pyproject.toml`, `requirements.lock`, `requirements-dev.lock`, `.python-version`: Python.
- `collector/src/collector/__init__.py`, `collector/tests/unit/test_smoke.py`: pacote e teste de fumaça.
- `package.json`, `package-lock.json`, `.nvmrc`: Supabase CLI.
- `frontend/`: projeto Vite, `src/App.test.tsx`, `.env.example`.
- `supabase/config.toml`, `supabase/.env.functions.example`, `.env.collector.example`.
- `.gitignore`: acrescentado `*.egg-info/`.

## Como conferir
- `pip install --require-hashes -r requirements-dev.lock && pip install --no-deps -e . && ruff check . && pytest` passa (1 teste).
- Em `frontend/`: `npm ci && npm run lint && npm run typecheck && npm test && npm run build` passa.
- `bash scripts/ci/check_bundle.sh frontend/dist` e `bash scripts/ci/check_guardrails.sh` passam.
