# T07 — Metodologia provisória dos campos

## O que foi feito
Foi criado `config/methodologies.yaml` (versão `provisoria-1`), com os quatro indicadores em `insufficient_metadata` e `quote_price` em `single_source`. O módulo `collector/src/collector/settings.py` carrega e valida o arquivo com Pydantic. O guia `docs/source-methodologies/acoes.md` explica os vereditos e o roteiro do autor.

## Por que foi feito assim
- Os sites respondem `403`, então nada foi lido; o veredito conservador evita `verified` sem prova (ADR 0002, E7; README 7.3).
- O enum de vereditos inclui `single_source`, que o exemplo do plano usa em `quote_price` embora o comentário do plano liste só três.
- Modelos com `extra="forbid"` e checagem das cinco métricas esperadas: erro de digitação no YAML falha cedo.

## O que foi descartado
Nenhum campo foi marcado `comparable`; isso é só do autor (P-04).

## Arquivos principais
- `config/methodologies.yaml`: metodologia provisória.
- `collector/src/collector/settings.py`: modelos e `load_methodologies`.
- `collector/tests/unit/test_methodologies.py`: testes.
- `docs/source-methodologies/acoes.md`: guia.

## Como conferir
`ruff check . && pytest` passa, incluindo veredito inválido rejeitado.

## Limitações e pontos de atenção
Os dados reais dependem do autor (P-04). A T14 deve tratar `comparable` como único veredito que permite `verified`/`divergent`.
